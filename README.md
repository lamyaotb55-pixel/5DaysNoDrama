# Workout Journey

Design Web app for workout plan and progress tracker. First step is asking the user to choose the plan (Lose Weight/Tone Up/Build Muscle). Each plan has 8 weeks. After choosing the plan each plan has five days, each day should show several workouts with Reps, Rounds and Weight Tracker. Each workout will have a media box to show the movement. each day should have a button of completion (Finish/Smashed!) with adding encouragement messages. There should be a dashboard showing the progress of each week. A restart button is available for repeating the plan with saving the old dashboard (history) and building another track. I want the style to be minimalist but colorful with max 4 colors. Adding Sky Blue and Electric Pink
